# 政区数据 · Political Map Data

[简体中文](#中文) · [English](#english)

## 中文

[countries.json](countries.json) 保存基础国家资料，[vector-draft.json](vector-draft.json) 保存矢量边界、编辑节点与自定义政区。[settlements-source.json](settlements-source.json) 列出绘制时参考的聚落。

草案和底图须使用相同的坐标系。修改边界后，应检查国家略图、人口及面积估算、沿海裁切和污染区域。数据加载入口见 [map-political-study.js](../../../src/map-political-study.js)。

## English

[Read in Simplified Chinese / 简体中文](#中文)

[countries.json](countries.json) contains baseline country records. [vector-draft.json](vector-draft.json) contains vector borders, editing nodes, and custom regions. [settlements-source.json](settlements-source.json) lists settlements used as drawing references.

The political draft and basemap must use the same coordinate system. After border edits, verify country insets, population and area estimates, shoreline clipping, and the pollution overlay. See [map-political-study.js](../../../src/map-political-study.js) for the loading entry point.

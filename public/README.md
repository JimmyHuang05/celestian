## English

Vite serves these files unchanged at their root-relative paths, such as `/mapplus/manifest.json`.

| Asset | Directory |
| --- | --- |
| MapPlus data and basemaps | [mapplus/](mapplus/README.md#english) |
| Original atlas | [map/world-240705-base-v2/](map/world-240705-base-v2/) |
| Dossier art and catalogs | [character-profile/](character-profile/) · [faction-profile/](faction-profile/README.md#english) · [gallery/](gallery/) |
| Flags and ship overlay | [flags/](flags/README.md) · [map-ships/](map-ships/README.md) |
| Production fonts | [fonts/](fonts/) · [Typography guide](../src/fonts/README.md#english) |

Data and source code reference filenames directly. Check those references before replacing or removing assets. Basemaps, territories, and placements in a release must use the same coordinate system.

## English

This directory preserves land outlines, mountains, waterways, and dashed gold sea routes for the original atlas. Keep layer coordinates and view boxes aligned when editing SVGs. Overlay exports on the intended basemap to check alignment. See the [map documentation](../../docs/maps/README.md#english).

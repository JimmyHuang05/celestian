## 中文

[App.jsx](App.jsx) 定义 React 路由，[main.jsx](main.jsx) 挂载主应用。根目录的独立 HTML 另有各自的页面入口。

| 路径 | 用途 |
| --- | --- |
| [pages/](pages/) · [components/](components/) | 页面容器和共享组件 |
| [map-ui/](map-ui/README.md) · [map-painter/](map-painter/README.md) | 地图交互、资料卡与涂色编辑 |
| [map-pollution-cores.js](map-pollution-cores.js) · [map-pollution-reports.js](map-pollution-reports.js) | 污染原点资料、危害估算与年度情报 |
| [pollution-1818.js](pollution-1818.js) · [map-pollution.js](map-pollution.js) | 1818 年污染范围与其渲染、存储 |
| [fonts/](fonts/README.md) | 全站字体角色与生成记录 |

改资料卡前先确认数据源，地图公开数据另见 [public/mapplus](../public/mapplus/README.md)。

## English

[Read in Simplified Chinese / 简体中文](#中文)

[App.jsx](App.jsx) defines the React routes, and [main.jsx](main.jsx) mounts the app. Standalone HTML documents at the repository root have their own entry points.

| Path | Purpose |
| --- | --- |
| [pages/](pages/) · [components/](components/) | Page containers and shared components |
| [map-ui/](map-ui/README.md#english) · [map-painter/](map-painter/README.md#english) | Map interaction, dossiers, and painting tools |
| [map-pollution-cores.js](map-pollution-cores.js) · [map-pollution-reports.js](map-pollution-reports.js) | Origin records, hazard estimates, and annual reports |
| [pollution-1818.js](pollution-1818.js) · [map-pollution.js](map-pollution.js) | 1818 pollution geometry, rendering, and storage |
| [fonts/](fonts/README.md#english) | Shared font roles and generated data |

Check the data source before editing a dossier. See [public/mapplus](../public/mapplus/README.md#english) for public map data.

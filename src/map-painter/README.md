## 中文

[MapPainterPage.jsx](../pages/MapPainterPage.jsx) 进入工作台。本目录包含地图编辑模型、沿岸处理、纹理、共享草稿和导出逻辑。旧版与 MapPlus 工作台共用一部分工具。

修改导出或存储格式前，应从实际工作台检查可打开的既有草稿、保存后重载，以及导出后的地理对齐。使用说明见[涂色工作台文档](../../docs/maps/painter.md)。

## English

[Read in Simplified Chinese / 简体中文](#中文)

[MapPainterPage.jsx](../pages/MapPainterPage.jsx) opens the workbench. This directory contains the editing model, coastline handling, textures, shared drafts, and exports. The original atlas and MapPlus share some of these tools.

When changing export or storage formats, check existing drafts, save and reload in the workbench, and verify geographic alignment after export. See the [painter guide](../../docs/maps/painter.md).

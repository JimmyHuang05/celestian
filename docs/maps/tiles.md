# 海陆图志瓦片底图

当前源图：工作区根目录 `WorldMap_240705_底图.png`，21600 × 10400。文字单独使用 `WorldMap_240705_文字标识.png` 描摹的 SVG。原图保留在源码站点目录外，不随网页发布。旧版带文字瓦片 `world-240705-v1` 保留作回退参考，当前页面不再加载。

## 生成

使用 Pillow，生成到一个新的版本目录，脚本拒绝覆盖现有目录：

```powershell
python scripts/build-map-tiles.py ../WorldMap_240705_底图.png public/map/world-240705-base-v2 --coordinate-system 2acc2256324424aaf482a78d194fab5bfd899e1643c632db5c2526c983b0bc5e
python scripts/trace-map-land.py
python scripts/trace-map-labels.py
python scripts/index-map-labels.py
```

当前输出为 512px WebP、质量 90，0–6 七个层级，共 1238 块，39,574,790 字节。`manifest.json` 保存原图 SHA-256、尺寸和各级网格。最高层保持源图像素分辨率，编码为有损 WebP。坐标身份与素材哈希分开：这次只拆分文字、没有改变地形位置，所以沿用原坐标身份，已有国家草稿与备份可继续使用；真正更换地形时不能沿用。

`MapPage.jsx` 使用 Leaflet CRS.Simple。坐标原点为图片左上，X 向右、Y 对应负纬度；最高级每像素一单位，层级 0 缩放为原图的 1/64。地图边界排除右侧及底部的瓦片补边。浏览器仅请求当前视野及一圈缓冲图块，放大后请求对应层级，不加载原图或旧标记数据。

Vite 自动复制 `public/map/`。部署需完整包含版本目录；原图不需要上传。替换地图时生成新版本目录，并修改共享配置 `src/map-assets.js` 的 `MAP_ROOT`，避免旧缓存混用。

## 文字标识

`labels.svg` 是独立透明的纯路径层，保持 21600 × 10400 坐标，共 1423 条路径、417852 字节。不是嵌入 PNG，也没有 OCR 或重排；旋转字形保留在原位置。采用原分辨率透明通道、阈值 128、polygon 描摹，不过滤细小点画。文字表面纹理替换为源图不透明像素的平均金色 `#937a57`，不能像文本框一样改字。

在三个原生分辨率样本上回渲染，二值字形交并比约 93.74%、95.18%、95.53%；细小笔画与抗锯齿边缘存在近似，不宣称是字体源文件的无损转换。已检查中英文、旋转标签及小字号排版。

前台文字使用独立 Leaflet pane；编辑器文字位于涂色画布上方，不参与正片叠底，也不截获画笔事件。两处都有「文字」开关。自动化检查用瓦片像素坐标验证缩放前后文字层的边界对齐，误差在两屏幕像素内。

## 地点标记恢复

`markers.json` 保存 2026-11-05 从旧公开 `/api/map/markers` 一次取回的 67 个标记（首都、主要城市、要塞、观测站、据点、遗迹等）。运行时只加载本地文件，不连接旧后台。只保留地点展示字段，不发布编辑者信息。地图的地点请求与瓦片、文字并行，加载失败不阻塞底图。

原标记坐标使用 10800 × 5200 图片的左下原点：新图像素 `x = 2 * lng`、`y = 10400 - 2 * lat`，再转换为 `CRS.Simple` 的 `[ -y / 64, x / 64 ]`。`src/map-markers.js` 统一处理坐标、图标与交互。无效或越界坐标跳过。已验证全部 67 个有效标记及缩放后的对齐，点击或 Enter/Space 可打开地点资料，移动端显示底部面板。

## 前台交互恢复

`src/map-regions.js` 使用归档 SVG 的原有分区，以及本地旧资料快照提供 82 个可交互区域。普通区域透明；污染、沦陷、深渊区域保留淡色覆盖。鼠标悬停加粗当前边线，触屏不依赖悬停；点击/Enter/Space 锁定并高亮关联领土，打开名称、外文名、状态、说明、领土预览和组/子组资料。follow_primary 按同一国家内的子组或主区域查找，避免跨国家同名子组误关联。局部污染与局部资料不因国家归属合并而抹平。没有对应资料的旧区域不响应点击。

资料卡与城市标记互斥，点击地图空白或关闭会恢复区域默认状态、清除点位高亮。选中位置自动偏移，为桌面左侧或手机底部资料卡让位。前台区域层当前使用归档的已配置几何，不自动发布编辑器的本地草稿。

搜索框支持中英文地点名、类型，以及区域名称/组/子组；类型筛选即时隐藏不匹配地点，但不会屏蔽国家与区域的搜索结果。搜索按主资料及局部状态去重，独立殖民地、污染区保留；同一主资料下的污染片段合为一项，优先使用带局部描述的片段定位。提供回中心、全图、缩放和文字开关；大陆校准留在编辑器。地点和区域元数据均为本地快照，未重新接通旧后台。

`node scripts/test-map-interactions.cjs` 验证悬停、关联领土、预览、还原、首都筛选、点位/区域搜索、手机资料卡和中心/全图控制。

## 第一阶段界面优化

`src/map-ui/` 分离搜索、资料卡、工具栏和图标。桌面搜索与资料卡统一为 360px；常用分类在搜索框下，其他分类按现有数据生成并显示数量。搜索结果按国家/区域与地点分组，支持方向键、Enter、Esc 和输入法组合输入。Esc 优先关闭搜索或显示设置，再关闭资料卡；关闭资料卡可将键盘焦点交还地图。

640px 及以下首次进入使用铺满可用高度的大陆视野，仍可一键查看全图。底部资料卡有摘要、半屏、展开三档，支持手柄拖动、按钮和键盘调整，正文独立触屏滚动。工具按钮和缩小后的音乐播放器随资料卡上移。校准轮廓不再占用前台工具栏，文字与回中心收进显示设置。

点位悬停与选中在原坐标上缩放，附带一次细环反馈；资料卡约 220ms 入场、180ms 退出，移动端高度吸附 260ms。地图移动只使用 Leaflet 的同步变换，定位目标先限制在地图边界内，避免结束后再次回弹。相同缩放级别平移 320ms，改变缩放级别定位 380ms；用户拖动可打断，系统减少动态效果模式下停用过渡。文字开关使用 180ms 透明度过渡，不给瓦片、区域或文字的空间变换添加独立缓动。

`node scripts/test-map-search.mjs` 检查资料去重、局部状态、分类隔离和原始数据不被修改。`node scripts/test-map-ui-phase1.cjs` 检查键盘搜索、手机初始视野、触屏阅读与拖动、320/390/640px 布局、减少动态效果，以及缩放过程中的逐帧图层对齐。

## 第二阶段探索功能

`src/map-ui/marker-visibility.js` 按缩放显示地点：低于 2.75 优先首都、主要城市；2.75 起加入要塞、观测站等；3.5 起允许所有类型。使用投影后的世界像素进行重叠避让，优先选中地点，再按类型重要性和稳定 ID 排序，不会因为平移而反复切换点位。主动分类筛选会打开地点层，并显示该类全部点位；搜索选中的地点即使地点层关闭也单独显示。此规则只影响呈现，不修改原坐标或搜索范围。观测站和基地补充独立图形，图例直接复用地图图标。

搜索国家时按实际 SVG 包围盒取景，优先本土数据，再取相邻片段中较大的领土集合；独立地区聚焦当地。资料卡提供「主要领土／此区域」及有需要时的「全部领土」。后者包含远处领地，二者都为桌面资料卡或手机半屏卡预留空间。几何分组仍以已配置的 group_id 为准；包围盒聚合只用于默认取景，不改变政治归属。临时取景范围容纳面板需要的边距，避免靠近原图边缘时目标被资料卡遮住。程序定位保留最近八个视野，可返回上一视图；关闭卡片不强制跳回。视图最低可缩至 -1，瓦片仍通过 minNativeZoom 使用原生 0 级，不会请求负层级文件。

图层面板包含地名、地点、国家疆域和特殊状态四项。国家疆域默认关闭；开启后，仅对有归属资料的区域使用稳定区分色。特殊状态独立开关，污染为实线、沦陷为虚线、深渊为点线，地图图例同时显示图形和文字。选中高亮始终保留。面板可滚动，有固定关闭入口；图例列出地点类型、状态，以及开启疆域层后的国家/区域颜色。悬停显示名称、归属和状态，选中其他国家时依然可用，拖动地图时立即收起提示。

浏览偏好保存在 localStorage 的 celestian-map-view-v2：视野、四类图层、分类、搜索文字及选中的资料。视野使用归一化中心和 coordinateSystemSha256 绑定地图；刷新或返回时恢复同一位置，恢复选中只恢复高亮/资料，不再次定位。版本或数值无效时回退默认，地图坐标身份不同则忽略旧视野与选择，存储不可用也不阻塞地图。前台偏好与编辑器 IndexedDB 草稿完全分离。面板的「恢复默认地图」恢复当前设备的初始视野、图层和筛选。

`node scripts/test-map-phase2.mjs` 检查点位分级、重叠优先级、国家取景和偏好校验。`node scripts/test-map-ui-phase2.cjs` 检查搜索例外、上一视图、主要/全部领土定位、选中后的悬停、图层与图例、刷新及资料恢复、重置和 320px 全图视野。

## 第三阶段地名与分享

`labels-index.json` 为原来的 1423 条字形路径增加 52 组地名/航线索引，包含人工核对的中英文名、原图包围盒、路径归属、类别和显示层级。`scripts/index-map-labels.py` 从原有 polygon 路径读取几何、合并相邻文字，再单独拆出俄提斯洋旁的欧佩里航线；覆盖断言确保每条路径只属于一个文字组。名称索引用于图层管理，原始 SVG 不改字形、位置或旋转，也不把海域名称硬套到旧国家资料上。重新描摹或更换文字后须重跑并检查分组；脚本发现分组数量变化会停止，不能直接沿用旧名称。文件保留来源 SVG 的 SHA-256 供一致性测试。

前台默认自动分级：大海域名从 1.5 级出现，其他地名按原字形尺寸从 2.5、3.5、4.25 级出现。整个文字组按重要性排序，以世界像素包围盒避让其他地名及当前可见点位，平移不重新排版。`src/map-labels.js` 只给原路径加分组和透明度，不引入独立空间变换；仍随 Leaflet 底图同步缩放/移动。图层面板的「完整原图」可显示全部文字，编辑器始终保留完整文字。此选择随浏览偏好保存；关闭文字总开关时两种模式均隐藏。索引缺失或路径覆盖不一致时退回完整原图并显示提示，不丢弃字形。

底图只等待 manifest；文字/索引、地点、区域各自并行获取。慢文字或失效索引不会阻塞底图、地点和区域交互；文字加载失败仍提供重试。

资料卡有分享地点/区域入口，桌面工具栏和图层设置提供分享当前视野。分享弹窗显示可手工复制的链接；剪贴板授权失败时选中链接，正常复制后显示反馈。Esc 只关闭分享，保留已选资料，并恢复键盘焦点。手机通过图层设置分享视野，避免底部工具栏过宽。

链接使用 `/map/?map=2&atlas=...&x=...&y=...&z=...&layers=1101&labels=auto`，可带一个 `point` 或 `region`。中心坐标为原图归一化值，atlas 为完整坐标身份；layers 顺序为文字、点位、疆域、状态。只记录公开目标、当前视野与图层，不包含搜索内容、编辑草稿或浏览历史。链接优先于本机上次的浏览偏好；接收方清空搜索/类型筛选，恢复资料和高亮而不再次触发定位。无效格式、未知地点/区域、地图版本不匹配都有明确提示；坐标身份不匹配时使用新图默认视野。URL 使用当前站点域名，因此本地预览生成本地链接，部署后生成对应正式域名的链接。

`node scripts/test-map-phase3.mjs` 检查路径完整性、索引来源、分级/避让和分享参数校验；`node scripts/test-map-ui-phase3.cjs` 验证分级与完整模式、刷新恢复、地点/区域/纯视野链接往返、未知与旧版链接、320px 分享弹窗、剪贴板失败退路、慢文字及索引缺失降级。前两阶段交互及逐帧图层同步继续回归。

## 原图装饰边框与铺满视野

`src/assets/map/atlas-frame.svg` 是可独立编辑的纯矢量边框：古铜色双层刻线、链式花纹、卷草角饰及四边罗盘饰章。SVG viewBox 为 2232 × 1112，中间透明开口从 (36, 36) 到 (2196, 1076)，与 21600 × 10400 的底图保持同一比例；四周各增加 360 个原图像素的装饰范围，不更改瓦片、地点、区域或草稿坐标。

`src/map-frame.js` 把边框挂在 Leaflet 的 470 层，使用扩大后的地理 bounds，跟随原图逐帧缩放和平移。边框及其 pane 不截获鼠标、触屏和地图拖动。原图与文字/区域仍使用原 bounds，只有浏览边界与「全图」取景包括装饰边框。SVG 随前台代码加载，不需要额外图片请求，编辑器不加载装饰边框。

普通首次打开及「恢复默认地图」在桌面、手机上都按原比例 cover 铺满整个地图视口；比例不同的方向裁出屏幕，可拖动查看。使用连续缩放值精确贴齐视口，避免 0.25 级取整后把边框全部裁掉。当前处于铺满比例时，改变窗口尺寸会重新适配比例、保留尽可能接近的中心。全图按钮按 contain 展示完整地图和整圈边框；普通缩小下限设为完整图范围，不再额外缩小一档。明确的国家全部领土视野、历史视野或分享链接可以按其自身范围定位。

浏览偏好增加 frameVersion: 1。旧版本保存的无选中资料的小缩略视野首次迁移为铺满；新的完整图选择、已有资料卡及明确的分享链接继续按原视野恢复。国家资料卡取景改为在应用缩小下限前计算真实包围盒，确保新增全图下限不会裁掉远处领地。

`node scripts/test-map-frame.cjs` 检查旧视野迁移、2400px 超宽屏与 320px 手机尺寸切换、比例不变、拖动同步、全图完整性、刷新与重置。第一阶段逐帧同步检查也包含边框开口与地图图层的对齐。

## 大陆轮廓

运行 `python scripts/trace-map-land.py`，从工作区 `WorldMap_240705_svg.png` 的透明通道按 128 阈值提取海陆边界。使用本地 vtracer，以原生 21600 × 10400 分辨率描摹，不裁切、不缩放、不滤除小岛。输出 `land.svg`（186 条矢量路径、326240 字节）与来源记录 `land.json`。路径编号只用于标识，不代表国家、势力或已命名的大陆。

SVG 与瓦片使用同一 bounds；大陆轮廓用于编辑器的陆地约束和校准，不再显示为前台工具。抽查全图和放大画面已对齐；将 SVG 回渲染至 2160 × 1040，与源图透明轮廓比较，陆地交并比为 99.739%，边界包围盒相同。此指标用于检查描摹误差，并非国家或地理数据的精度声明。矢量描摹存在少量海岸边缘近似。
